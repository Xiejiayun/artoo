# 手动计划编辑与草稿

Plan 的手动编辑器支持删除任意任务及上移/下移。编辑期使用稳定的浏览器临时 ID；提交时按当前顺序生成既有 TaskSpec 的数字字符串下标。移动保留依赖对象，删除清除对该任务的依赖，不会把它指向碰巧占据同一下标的其他任务。依赖可指向显示顺序中的任意其他任务，循环仍由服务端图校验拒绝，失败保留草稿。

未提交的 rationale、任务文字、能力与依赖存储在当前浏览器的 localStorage，键包含 API 服务端 scope、组织、用户和 Goal ID，格式版本为 1。不会增加服务端协议字段。关闭编辑器或刷新后重新打开即可恢复；提交被服务端确认后清除，失败保留。清理绑定提交时的草稿快照，旧编辑器的迟到成功不会删除重新打开后写入的新内容；成功回调不会通过 effect 再写回刚清除的草稿。无法清除已提交草稿时显示警告。

“Discard saved draft” 显式删除当前草稿并开始空计划。无效 JSON、重复任务 ID、缺失依赖等不可恢复草稿保留原副本并锁定编辑，等待用户主动丢弃；存储不可用/容量不足时保留当前编辑器内的内容并显示提示。草稿不保存会话令牌或配对凭据；它包含用户输入的计划文字，因此复用已有退出、失效会话及桌面断开时的草稿清理路径。清理事件也清空已挂载编辑器并阻止迟到响应重新开启编辑。

该存储用于恢复未提交的手动编辑，不承诺多标签同步或服务端备份。原有提交/计划接受/任务物化及授权流程不变。
