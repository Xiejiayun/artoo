## 当前交付目标

多台已配对电脑上的多个 Agent 加入一个项目团队：围绕 Goal 规划，经用户接受后，
互不依赖的任务在隔离目录并行；依赖任务等待上游验收并取得固定版本的产物；
团队可提出问题、记录阻塞与交接、评审返修，最后由用户验收。

电脑开关机、重启、唤醒完全排除。新增发布目标和 Provider 扩展后置。
精确成本要求保留，费用预算继续关闭。
