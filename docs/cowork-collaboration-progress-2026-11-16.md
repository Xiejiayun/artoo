团队可提出问题、记录阻塞与交接、评审返修，最后由用户验收。

精确成本要求保留，费用预算继续关闭。

实际进程执行、日志/结果回传与任务停止。iOS、macOS 及其他平台开发和专项验收
全部暂停，已提交代码保留；Linux 新资格与额外 Provider/发布目标不继续扩张。
Windows 桌面客户端（界面/壳）也暂停。当前仅 Web、服务端与 Windows daemon 活跃，
停止新增功能，收口后统一验证这条任务流程。

收口顺序：优先用普通配对执行路径验证多机协作，当前 Windows 新调度组合只完成
正在进行的候选接线，不继续扩张。T19 不等待后置平台、Provider 或发布目标。
显式 Agent 产物意见任务已补首批实现（#192–#194、#199），核心受控浏览器和真实 MCP
输入回归已通过，完整验收仍未通过；它固定候选文件并
由另一 Agent 返回报告，用户明确决定是否返修，不等于整工作区可信独立验证或自动验收。
