# Review Feedback Context Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver actual Request Changes comments to every subsequent ordinary execution context for the same task, retaining exact content and review provenance.

**Architecture:** Add an optional, versioned `review_feedback` section to `ContextPack`. In the assign transaction, the context builder reads existing `review.completed` events for the current organization/project/task in global position order, selects nonblank `changes_requested` comments, and copies provenance and comment text without manufacturing messages or reviewed-run associations. Assistant-turn and discussion contexts omit this section.

**Tech Stack:** TypeScript, Zod, Drizzle, Fastify inject integration tests, embedded PGlite, Vitest, Node 24.
