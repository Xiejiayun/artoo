# Project navigation

Owners and admins can click the **+** beside **Projects** to open **New project**
directly. Enter a name and optional execution workspace, then save to select the
new project. Cancel or Escape dismisses the form; a pending save must finish
before it can be dismissed. The same form is available in Settings.

When a mouse leaves the selected project row, Web clears the project and task
selection. An open project content page returns to Overview, which asks the user
to select a project. No other project is automatically selected. Leaving an
unselected row has no effect, and machine, agent and settings pages keep their
current route.

Keyboard users can focus a project and press Enter or Space, then tab to its
content without moving the mouse across the row. Touch activation keeps the
project selected when the touch ends. Dismissal only affects the current UI;
it does not cancel tasks, pause goals, stop runs or delete project data.
