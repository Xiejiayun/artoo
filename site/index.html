Artoo for iOS

Your team's work, within reach.

Follow conversations, review approvals, and manage agent work through your team's Artoo server.

Artoo is a native client for an existing team workspace. Your team provides the server, account access and execution computers. Pair your phone using a code created by your own account in the team web app.

Preparing for release

The first public iOS release is planned to be free. App Store availability will be announced after release verification and Apple's review. There is no download or availability claim on this page.

Before connecting

Ask your team administrator for the HTTPS server address, access instructions and the team's privacy and retention policy. Never share a pairing code or use another person's account code.

Read the iOS privacy policy or get help with pairing and support.
